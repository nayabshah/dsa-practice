# DSA Practice

Practice repository for Data Structures and Algorithms in:
- C++
- Python
- JavaScript

## Structure

- `cpp/` - C++ solutions
- `python/` - Python solutions
- `javascript/` - JavaScript solutions
- `problems/` - Problem notes and statements

## Suggested workflow

1. Pick a problem and create matching files in each language (optional).
2. Add approach notes in `problems/`.
3. Keep naming consistent, e.g. `two_sum`, `binary_search`.
4. Commit regularly.

Happy coding 🚀
